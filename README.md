# Forte Wither — локальный сервис видеоанализа

Python/FastAPI сервис с веб-интерфейсом и API для загрузки `.mov`, асинхронного анализа, таймкодов и JPEG кадров-доказательств. Видео и модель обрабатываются локально. После установки зависимостей работа сервиса и анализ не требуют облачных AI API или доступа в интернет.

## Быстрый запуск

Нужен Python 3.10–3.12. На macOS/Linux (пример для Python 3.12):

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000`. При первом запуске сервис создаёт случайный API ключ в `.api_key` (файл исключён из Git); для постоянного ключа задайте `API_KEY` до запуска. Ключ для жюри можно получить командой `cat .api_key`. Для доступа из одной сети используйте `--host 0.0.0.0` и адрес компьютера в этой сети. Для удалённой проверки нужен публичный HTTPS URL через сервер или настроенный reverse proxy; `0.0.0.0` и локальный IP не являются публичным URL. Храните ключ в защищённом секрете и не публикуйте `.api_key`.

## Подготовка датасета и обучение

1. Положите обучающие `.mov` файлы в `data/videos/`.
2. Заполните `data/annotations.csv` в UTF-8: `video,label,timecode_sec,type`. `label=1` означает возможное нарушение; у него должен быть таймкод в секундах. Для обучения классификатора типа заполните `type` числом 1–11 из справочника ниже. `label=0` означает ролик без нарушения, таймкод и тип оставьте пустыми. Имена файлов должны точно совпадать с файлами в `data/videos/`.
3. Обучите локальную модель:

```bash
python train.py --annotations data/annotations.csv
```

Либо после запуска вызовите защищённый `POST /api/v1/train` с JSON `{"annotations_csv":"data/annotations.csv","threshold":0.35,"event_type":"Возможное визуальное событие"}` и заголовком `X-API-Key`.

Результат обучения сохраняется в `data/model.joblib`. Модель обнаружения и классификатор типа — `ExtraTreesClassifier` поверх локальных HOG, цвета и движения между кадрами. Классификатор типа использует только положительные примеры с заполненным столбцом `type`. Модель не требует скачивания весов и использует CPU. Повторяйте обучение после пополнения набора.

Для настройки доли срабатываний можно изменить `--threshold` или `DETECTION_THRESHOLD` (по умолчанию 0.35). Более низкий порог обычно повышает полноту и число ложных тревог. Команда обучения возвращает оценку по видео, отложенным от обучения. Рассматривайте её как ориентир на небольшом наборе, не как гарантию на новых ракурсах.

Справочник типов: 1 — передача ценностей вне специального устройства; 2 — нарушение порядка пересчёта наличных; 3 — оставление денежных средств без присмотра; 4 — открытый или незапертый сейф; 5 — оставление рабочего места без блокировки; 6 — несанкционированный доступ посторонних лиц в кассовую зону; 7 — оставление инкассаторской сумки без присмотра; 8 — смешивание денежных средств разных операций; 9 — посторонние предметы, еда и напитки на рабочем месте; 10 — оставление документов и печатей без присмотра; 11 — передача ценностей неуполномоченному лицу. Для текущей классификации типа в таблице есть очень мало примеров: типы 2, 10 и 11 отсутствуют, а типы 1, 7, 8 и 9 представлены одной записью каждый. Предсказание категории остаётся предварительным.

## API для жюри

Все API endpoints, кроме `/health`, требуют `X-API-Key`.

```bash
curl -X POST http://localhost:8000/api/v1/analyze \
  -H 'X-API-Key: ВАШ_КЛЮЧ' \
  -F 'file=@video_017.mov'
```

Ответ содержит `job_id`. Запрашивайте статус до `done`:

```bash
curl http://localhost:8000/api/v1/jobs/JOB_ID -H 'X-API-Key: ВАШ_КЛЮЧ'
```

При завершении ответ включает `verdict` (`no_violation` или `violation`), список `violations`, `type_id`, `type`, `type_confidence`, `timecode_sec`, описание, `legal_qualification` и до трёх `evidence_frames` с `image_base64`. `legal_qualification.status` различает норму с возможной применимостью (`normative_candidate`), условно применимую норму (`conditional_norm`) и категорию, требующую сверки с внутренними правилами банка (`internal_policy`). Во время обработки ответ задачи содержит `progress_percent` и `progress_message`; итог также содержит `notice`, `model_trained`, `video_duration_sec` и `fps`. Справочник доступен через `GET /api/v1/violation-types` и содержит правовые основания по категориям. Задачи хранятся в памяти процесса, поэтому после перезапуска ранее выданные `job_id` недоступны. Для одного процесса используйте один worker.

Интерактивная документация API: `/docs`. Проверка готовности: `/health`.

## Правовая основа и пределы вывода

Правовая карта в приложении проверена 18.10.2026 по ИПС «Әділет». Базовый акт — [действующее постановление Правления Национального Банка РК от 29.11.2019 № 231](https://adilet.zan.kz/rus/docs/V1900019680), включая изменения, вступившие в силу 20.07.2026. Также учтены [Правила организации охраны и устройства помещений банков, постановление № 14 от 24.02.2020](https://adilet.zan.kz/rus/docs/V2000020075), и [Инструкция по антитеррористической защите уязвимых расчетно-кассовых отделений банков](https://adilet.zan.kz/rus/docs/V2400034348), которая применяется только в установленной для нее сфере.

В приложении категории с прямыми процедурными нормами помечаются как возможная применимость нормы; категории, для которых требуется внутренний регламент банка, помечаются отдельно. Это не заключение о совершении правонарушения: камера не устанавливает полномочия человека, фактический пересчет и бухгалтерский учет, непрерывность надзора или действие внутреннего распорядка. Окончательную квалификацию должен выполнить уполномоченный сотрудник по актуальным нормам и внутренним документам.

Сервис обучает бинарный детектор события и отдельный классификатор типа по столбцу `type`. Текущая таблица содержит 60 размеченных видео, в том числе отражённые копии; оригинал и отражённая копия объединяются в одну группу при отложенной проверке. Типы 10 и 11 пока не представлены, а типы 1, 2, 7, 8 и 9 имеют только по одному исходному положительному эпизоду. Поэтому классификатор типов для этих категорий ненадёжен. На текущей групповой проверочной выборке получены balanced accuracy 0.722, precision 1.000 и recall 0.444 при пороге 0.35. Это оконные метрики на небольшой выборке, не оценка качества на новых камерах; проверяйте каждый фрагмент. Для надёжной оценки нужны независимые ролики с разными ракурсами и условиями съёмки.

## Запуск в изолированном контуре

Соберите/установите зависимости и положите видео и `data/model.joblib` до переноса. После этого сервис не вызывает внешние API и не загружает предобученные веса. Для полноценного развёртывания API в банковской сети поставьте TLS reverse proxy перед Uvicorn, задайте секрет `API_KEY` и ограничьте сетевой доступ. Ограничение размера загрузки по умолчанию — 300 МБ (`MAX_VIDEO_MB`).
